# Third-Party Pixel Assets

The current pet sprite set is adapted from these open-source assets:

## Tiny Creatures

- Source: [Tiny Creatures - OpenGameArt](https://opengameart.org/content/tiny-creatures)
- License: `CC0 1.0`
- Used for:
  - `CUB CAT` base sprite
  - `TIGER` base sprite
  - `LION` base sprite

## Pixel Robot

- Source: [Pixel Robot - OpenGameArt](https://opengameart.org/content/pixel-robot)
- License: `CC0 1.0`
- Used for:
  - `ROBO CAT` base sprite

## Notes

- Sprites were cropped, resized, and converted into embedded RGB565 arrays for the ESP32-C6 display.
- The project keeps only the adapted runtime-ready versions in code and the downloaded sources under `third_party_assets/`.
